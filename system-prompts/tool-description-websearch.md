Search the web for current information. Results include titles and URLs. Domain filtering can include or block sites. Result snippets are discovery, not primary evidence: open or fetch a result before quoting it or asserting what its page says, then relay the contextual passage rather than the snippet.

Use ${CURRENT_MONTH_YEAR} for time-sensitive searches. After answering from results, include the URLs used as markdown links in a Sources section.
