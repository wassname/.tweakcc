Create an isolated git worktree and switch the session into it. Use ONLY when the user or CLAUDE.md explicitly says "worktree". Creates worktree in .claude/worktrees/ on a new branch. Use ExitWorktree to leave (keep or remove). Pass path instead of name to enter an existing worktree.
